## Типы данных

Размер типа в байтах возвращает оператор `sizeof()`: `sizeof(int)`, `sizeof(x)`.

| Тип           | Размер (обычно) | Описание                                                          |
|---------------|-----------------|-------------------------------------------------------------------|
| `bool`        | 1 байт          | Логический тип: `true` (1) или `false` (0)                        |
| `char`        | 1 байт          | Один символ или его ASCII-код: от -128 до 127 (`unsigned`: 0–255) |
| `int`         | 4 байта         | Целое число                                                       |
| `long long`   | 8 байт          | Большое целое число                                               |
| `float`       | 4 байта         | Число с плавающей точкой (~7 значащих цифр)                       |
| `double`      | 8 байт          | Число с плавающей точкой двойной точности (~15 цифр)              |
| `std::string` | —               | Строка из стандартной библиотеки, нужен `#include <string>`       |

## Пространства имён (namespace)

Пространства имён организуют код и предотвращают конфликты имён.
`std` — пространство имён стандартной библиотеки C++.

## Hello, World!

Без `using namespace` — перед каждым именем из стандартной библиотеки пишем `std::`:

```cpp
#include <iostream> // std::cin, std::cout, std::cerr, std::clog

int main() {
    std::cout << "Hello World" << std::endl;
    return 0;
}
```

С `using namespace std;` — префикс можно не писать:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World" << endl;
    return 0;
}
```

> В учебных программах `using namespace std;` удобен, но в заголовочных файлах и больших
> проектах его лучше не использовать — он «засоряет» глобальное пространство имён.

## Русский язык в консоли

```cpp
#include <clocale> // setlocale
#include <iostream>
using namespace std;

int main() {
    setlocale(LC_ALL, "Russian"); // включаем русскую локаль (актуально для Windows)

    int number;
    cout << "Введите число: ";
    cin >> number;
    cout << "Число " << number << ", умноженное на 2 = " << number * 2 << endl;
    return 0;
}
```
