## Логические операторы

| Оператор | Альтернативная запись | Значение    |
|----------|-----------------------|-------------|
| `&&`     | `and`                 | Логическое И   |
| `\|\|`   | `or`                  | Логическое ИЛИ |
| `!`      | `not`                 | Логическое НЕ  |

## Инкремент и декремент

- `++` — увеличивает значение на 1
- `--` — уменьшает значение на 1

| Форма      | Название    | Что возвращает                          |
|------------|-------------|-----------------------------------------|
| `++x`, `--x` | Префиксная  | Сначала меняет значение, затем возвращает **новое** |
| `x++`, `x--` | Постфиксная | Возвращает **старое** значение, затем меняет его     |

```cpp
int x = 5;
int a = ++x; // x = 6, a = 6
int b = x++; // b = 6, x = 7
```

## switch – case

`switch` сравнивает значение с набором констант. Не забывайте `break`, иначе выполнение
«провалится» в следующий `case`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int day;
    cin >> day;

    switch (day) {
    case 6:
    case 7:
        cout << "Выходной" << endl;
        break;
    case 1:
        cout << "Понедельник — день тяжёлый" << endl;
        break;
    default:
        cout << "Будний день" << endl;
        break;
    }
    return 0;
}
```

## Случайные числа

```cpp
#include <cstdlib> // rand, srand
#include <ctime>   // time
#include <iostream>
using namespace std;

int main() {
    srand(time(nullptr));     // инициализируем генератор текущим временем
    int a = rand();           // случайное число от 0 до RAND_MAX
    int b = rand() % 11 + 5;  // случайное число от 5 до 15
    cout << a << "\t" << b << endl;
    return 0;
}
```

> В современном C++ для случайных чисел лучше использовать `<random>`:
> `std::mt19937 gen(std::random_device{}()); std::uniform_int_distribution<int> dist(5, 15);`
