## C-строки (массив символов)

C-строка — это массив `char`, который заканчивается нулевым символом `'\0'`.

```cpp
#include <iostream>
using namespace std;

int main() {
    char str_arr[] = "string"; // "..." — строка (7 байт вместе с '\0')
                               // '...' — один символ
    cout << str_arr << endl;
    return 0;
}
```

## std::string

`std::string` сам управляет памятью, умеет склеиваться через `+` и знает свою длину.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str = "Hell";
    char arr[] = "Hell";

    str += "o";                   // конкатенация
    cout << arr << endl;          // Hell
    cout << str << " " << str.size() << endl; // Hello 5
    return 0;
}
```

## Функции для C-строк — cstring

Подключаются через `#include <cstring>`.

| Функция   | Что делает                                                              |
|-----------|-------------------------------------------------------------------------|
| `strlen`  | Возвращает длину строки (без `'\0'`)                                    |
| `strcpy`  | Копирует строку в другую строку                                         |
| `strncpy` | Копирует не более `n` символов                                          |
| `strcmp`  | Сравнивает две строки (`0` — равны)                                     |
| `strcat`  | Дописывает одну строку в конец другой                                   |
| `strncat` | Дописывает не более `n` символов                                        |
| `strchr`  | Находит первое вхождение символа                                        |
| `strrchr` | Находит последнее вхождение символа                                     |
| `strstr`  | Находит первое вхождение подстроки                                      |
| `strspn`  | Длина начального участка, состоящего только из символов заданного набора |
| `strcspn` | Длина начального участка до первого символа из заданного набора         |
| `strtok`  | Разбивает строку на токены по разделителям                              |
