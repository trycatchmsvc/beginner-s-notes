## cout и printf

```cpp
#include <cstdio>
#include <iostream>
#include <string>
using namespace std;

int main() {
    char text_char_ascii = 68; // символ с ASCII-кодом 68 — это 'D'
    char text_char = 'D';
    string text_string = "Hello World 4;3%!";

    cout << text_char_ascii << endl;
    cout << text_char << " " << text_string << endl;

    printf("Hello World\n");
    printf("%s\n", text_string.c_str()); // printf не умеет работать с std::string напрямую
    return 0;
}
```

> Никогда не передавайте строку в `printf` первым аргументом (`printf(text)`): если в ней
> окажется `%`, `printf` воспримет его как спецификатор формата. Правильно — `printf("%s", text)`.

## Форматирование вывода — iomanip

Манипуляторы подключаются через `#include <iomanip>`.

| Манипулятор       | Что делает                                                                     |
|-------------------|--------------------------------------------------------------------------------|
| `setw(n)`         | Минимальная ширина поля для **следующего** значения                             |
| `setfill(c)`      | Символ-заполнитель для пустых мест (по умолчанию пробел)                      |
| `left` / `right`  | Выравнивание по левому / правому краю (по умолчанию `right`)                  |
| `fixed`           | Вещественные числа в фиксированном формате (без экспоненты)                   |
| `scientific`      | Вещественные числа в научной нотации (`1.23e+03`)                              |
| `setprecision(n)` | Количество знаков после запятой (вместе с `fixed`)                             |
| `showpoint`       | Всегда показывать десятичную точку                                             |
| `noshowpoint`     | Не показывать лишнюю десятичную точку                                          |

```cpp
cout << setw(8) << setfill('.') << left << 42 << endl;  // 42......
cout << fixed << setprecision(2) << 3.14159 << endl;    // 3.14
```

## Спецификаторы формата printf

**Целые числа**

| Спецификатор  | Вывод                                         |
|---------------|-----------------------------------------------|
| `%d`, `%i`    | `int` в десятичной системе                    |
| `%ld`, `%lld` | `long`, `long long`                           |
| `%u`          | `unsigned int`                                |
| `%x`, `%X`    | Шестнадцатеричная система (строчные/заглавные) |
| `%o`          | Восьмеричная система                          |

**Числа с плавающей точкой**

| Спецификатор | Вывод                                                  |
|--------------|--------------------------------------------------------|
| `%f`         | `float` или `double`                                   |
| `%e`, `%E`   | Экспоненциальная форма, например `1.23e+03`            |
| `%g`, `%G`   | Обычная или экспоненциальная — что короче              |

**Символы и строки**

| Спецификатор | Вывод                      |
|--------------|----------------------------|
| `%c`         | Один символ (`char`)       |
| `%s`         | C-строка (`char*`)         |

Ширину и выравнивание можно задать прямо в спецификаторе: `%10d` — ширина 10 с выравниванием
вправо, `%-10d` — влево, `%.2f` — два знака после запятой.

## scanf

`scanf` читает данные по формату. В C++ удобнее и безопаснее `cin`, но `scanf` встречается
в учебных задачах.

```cpp
#include <cstdio>

int main() {
    int a;
    scanf("%d", &a); // передаём адрес переменной!
    printf("a = %d\n", a);
    return 0;
}
```

> Visual Studio считает `scanf` небезопасной и выдаёт ошибку C4996. Её можно отключить,
> написав `#define _CRT_SECURE_NO_WARNINGS` **до** всех `#include`, либо использовать
> `scanf_s` — но это расширение Microsoft, и в GCC/Clang его нет.
