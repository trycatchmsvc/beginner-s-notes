# Beginner's Notes — C++

Конспект и решения учебных задач по C++ для начинающих.

## Структура репозитория

```
.
├── notes/        # конспект по C++, разбитый на главы
├── tasks/        # решения учебных задач
│   ├── z-tasks/      # задачи Z1–Z39 (блоки по 3 задачи)
│   ├── practice/     # практические работы PR1–PR21
│   ├── algorithms/   # алгоритмы и структуры данных
│   └── projects/     # небольшие самостоятельные программы
├── playground/   # черновики, эксперименты и сторонние примеры
└── Makefile      # проверка компиляции всех задач
```

## Сборка и запуск

Нужен компилятор с поддержкой C++17 (GCC, Clang или MSVC).

```bash
# собрать и запустить одну программу
g++ -std=c++17 -Wall tasks/z-tasks/block-01/z01.cpp -o z01 && ./z01

# то же через make
make run FILE=tasks/z-tasks/block-01/z01.cpp

# проверить, что компилируются все задачи
make check
```

Qt-проекты ([pr21-qt-journal](tasks/practice/pr21-qt-journal), [toynote](playground/toynote))
открываются в Qt Creator через `.pro`-файл.
